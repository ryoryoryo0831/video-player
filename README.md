# ビデオプレイヤー

- `index.html` … ブラウザ版（ダブルクリックで開くだけで使えます）
- `android/` … Android アプリ版（Kotlin + libVLC：VLC と同じ再生エンジン）

## Android 版のインストール

1. GitHub に push すると、GitHub Actions が自動で APK をビルドします。
2. スマホでこのリポジトリの **Releases**（最新版）を開き、`VideoPlayer-*.apk` をダウンロード。
3. 「提供元不明のアプリ」のインストールを許可してインストール。

## Android 版の機能

- 端末内の動画を一覧表示（サムネイル・再生時間・視聴位置バー付き）、検索・並べ替え
- 下のタブで「動画」「音楽」「フォルダ」「履歴」「プレイリスト」を切り替え
  - 音楽：曲・アルバム・アーティスト別の一覧、ジャケット表示
  - フォルダ：内部ストレージ・SDカードの中をたどって再生（「2話」→「10話」の順に並ぶ）
  - 履歴：最近再生した動画（最大200件）
  - プレイリスト：作成・名前変更・削除・並べ替え。動画やフォルダを長押しして追加
- 「ファイルを開く」から任意の動画を選択、他アプリの「このアプリで開く」にも対応
- 続きから再生（再生位置を自動保存）、連続再生、シャッフル、リピート（すべて／1本）
- VLC と同じ再生エンジン（libVLC）で、MKV / AVI / WMV / FLV など、AC3・DTS 音声、ASS 字幕にも対応
- 字幕：同じ名前の字幕ファイル（.srt / .ass など）を自動で読み込み（Shift_JIS も自動変換）、手動追加、トラック切替、タイミング調整
- 音声トラックの切替・タイミング調整、再生速度（0.25〜4倍）、画面サイズ切替、画面ロック
- ジェスチャー
  - 左側を上下スワイプ：明るさ ／ 右側を上下スワイプ：音量
  - 左右スワイプ：シーク
  - ダブルタップ：左=10秒戻る、右=10秒進む、中央=再生/一時停止
- 動画の縦横に合わせて画面を自動回転（右下のボタンで手動切替）
- ピクチャーインピクチャー（ホームに戻ると小窓で再生継続）
- 音楽・バックグラウンド再生
  - 画面を消しても再生が続き、通知・ロック画面・イヤホンのボタンで操作できる
  - 音楽の再生画面（ジャケット、シャッフル、リピート、再生キュー）とミニプレイヤー
  - イコライザー（VLC と同じプリセット・10バンド）、スリープタイマー
  - 動画の画面を離れたときの動作を「小窓で再生／音声だけ再生／一時停止」から選べる
- ネットワーク再生
  - 「フォルダ」タブのトップに、同じネットワークの DLNA サーバー・共有フォルダを自動で表示
  - NAS（SMB）・FTP・FTPS・SFTP・NFS のサーバーを登録して閲覧・再生（ログイン情報はアプリ内に保存）
  - 「URLを開く」で http・https・rtsp などのストリーミングを再生（.m3u などのプレイリスト URL にも対応）
- 再生画面の細かい機能：A-Bリピート、音量ブースト（最大200%）、スクリーンショット、チャプター移動
- 設定画面：字幕の大きさ・色・縁取り・太字・背景、続きから再生、画面を離れたときの動作、自動回転、ハードウェアデコード、ジェスチャーごとのオン/オフ、ダブルタップの秒数
- 動画タブ：すべて／フォルダ別、リスト／グリッド表示。フォルダタブ：今いる場所を上に表示（タップで戻れる）
- キャスト：同じ Wi-Fi の Chromecast などに動画・音楽を送って再生
- Android TV：TV のホーム画面に表示、リモコン（決定・十字キー・再生ボタン）で操作
