# iPhone 版 Orbit のインストール手順

パソコン（Windows）と SideStore を使って、iPhone に Orbit を入れる手順です。

---

## 始める前に確認すること

次の準備が終わっていることを確かめてから始めてください。

- [ ] iPhone に **LocalDevVPN**（App Store）を入れて、「Connect」でつないだことがある
- [ ] パソコンに **iTunes**（Apple のサイトからダウンロードする版。Microsoft Store 版ではない）が入っている
- [ ] パソコンに **iloader**（公式の GitHub「nab138/iloader」か iloader.app からダウンロードしたもの）が入っている
- [ ] iPhone に**パスコード**を設定している
- [ ] **USB ケーブル**と **Wi-Fi** がある

---

## 手順3　SideStore を iPhone に入れる（パソコンを使う・最初の1回だけ）

### 3-1. iPhone をパソコンにつなぐ

1. iPhone を USB ケーブルでパソコンにつなぎます。
2. iPhone に「**このコンピュータを信頼しますか？**」と出たら「**信頼**」を押し、パスコードを入力します。

### 3-2. iloader で SideStore を入れる

1. パソコンで **iloader** を起動します。
2. **Apple ID** でサインインします。
3. つないだ **iPhone を選びます**。
4. 「**SideStore をインストール**」を選びます。
   - 必要な設定ファイル（ペアリングファイル）も自動で入ります。
5. 終わるまで待ちます。

### 3-3. iPhone で SideStore を使えるようにする

1. **設定 → 一般 → VPNとデバイス管理** を開き、自分の Apple ID を選んで「**信頼**」を押します。
2. **設定 → プライバシーとセキュリティ → デベロッパモード** をオンにします。
   - iPhone が再起動します。再起動後に「オンにする」の確認が出たら、オンにします。
3. **SideStore** を開いて、最初の設定を済ませます。

> **うまくいかないとき**
> エラーの文言をそのまま控えてください。iloader の記録は、パソコンの
> `%APPDATA%\me.nabdev.iloader\logs` に残ります。

---

## 手順4　Orbit を入れる（iPhone だけで操作）

### 4-1. Orbit のファイルをダウンロードする

1. iPhone の **Safari** で、iPhone 版のページを開きます。
   - 最初の版：https://github.com/ryoryoryo0831/video-player/releases/tag/ios-build-2
   - 新しい版が出たら、そのページのアドレスを別に伝えます。
2. 少し下にある「**Assets**」の欄を開きます（閉じていたらタップ）。
3. **Orbit-iOS-1.0.〇.ipa** をタップします。
4. 「ダウンロードしますか？」と出たら「**ダウンロード**」を押します。
5. ファイルは「ファイル」アプリの「**ダウンロード**」フォルダに入ります。

### 4-2. SideStore で入れる

1. **LocalDevVPN** を開いて「**Connect**」でつなぎます。
   - つながっていないと SideStore はインストールできません。
2. **SideStore** を開き、下の「**My Apps**」タブを押します。
3. 左上の「**＋**」を押します。
4. 「ダウンロード」フォルダの **Orbit-iOS-1.0.〇.ipa** を選びます。
5. 1〜2分待ちます。
   - Apple ID のサインインを求められたら、手順3と同じ Apple ID を入力します。
6. ホーム画面に **Orbit のアイコン**（青→紫の再生マーク）が出たら完了です。

### 4-3. 起動して確かめる

1. Orbit をタップして起動します。
   - 「**信頼されていないデベロッパ**」と出たら、**設定 → 一般 → VPNとデバイス管理** で自分の Apple ID を「信頼」します。
2. 「ファイル」アプリの「**このiPhone内 › Orbit**」フォルダに動画を1本コピーします。
3. Orbit の「**動画**」タブにその動画が出て、再生できれば成功です。

---

## 困ったとき

| 起きたこと | やること |
|---|---|
| 「＋」を押しても何も起きない・エラーになる | LocalDevVPN がつながっているか確認し、SideStore を閉じて開き直す |
| 「アプリの上限に達しました」と出る | 無料の Apple ID は SideStore を含めて **3つまで**。ほかに SideStore で入れたアプリがあれば外す |
| Orbit が起動してすぐ落ちる | Orbit 側の問題の可能性があります。どこまで表示されたかを伝えてください |
| 7日たって Orbit が開かなくなった | LocalDevVPN をつないで、SideStore の「My Apps」で「**Refresh All**」（すべて更新）を押す |

---

## 覚えておくこと

- **期限の延長（7日ごと）**：LocalDevVPN をつないで、SideStore で「Refresh All」。自動更新を設定すれば、ほぼ何もしなくて済みます。
- **新しい版への更新**：新しい .ipa をダウンロードして、4-2 と同じ手順で入れると上書きされます。**履歴などのデータは消えません。**
- どちらも **LocalDevVPN がつながっている状態**で行います。
