## ビルドと公開の流れ

ローカルには Android SDK・Xcode・Mac が無いので、**ビルドはすべて GitHub Actions** で行う。

1. 作業用ブランチ **`main-t49pwm`** で変更して push する。
   - `android/**` を変えると Android のビルド（`.github/workflows/android.yml`）が走る。
   - `ios/**` を変えると iPhone のビルド（`.github/workflows/ios.yml`、Mac の環境）が走る。
   - 作業用ブランチでは**ビルドとテストだけ**行い、公開はしない。
2. ビルドが通ったらユーザーに報告し、許可をもらってから **main に早送り（fast-forward）で反映**する。
   - `git push origin main-t49pwm:main`
3. main に入ると自動で Releases に公開される。
   - **Android**：タグ `build-N`、名前「Orbit 1.0.N」、**最新版（latest）にする**。
   - **iPhone**：タグ `ios-build-N`、名前「Orbit iOS 1.0.N」、**最新版にはしない**（Android の最新版ページを変えないため）。
4. バージョンの末尾 N は、それぞれのワークフローの実行番号。

### ビルドの状況の確かめ方

- `gh` は使えない。GitHub MCP のツールか、公開 API（`curl https://api.github.com/repos/ryoryoryo0831/video-player/actions/runs/<id>`）で確認する。
- 待つときは、裏で動かすコマンドで完了を待つ（`sleep` で待たない）。

### 署名

- Android は GitHub の Secrets（`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD`）の鍵で署名する。main で鍵が無いと公開を中止する。
- 鍵の元ファイル（`release.p12`）はユーザーの PC の `signing/` フォルダと Google ドライブにある。リポジトリには入れない。
- iPhone 版は署名しない .ipa を作り、SideStore が入れるときに署名する（無料の Apple ID・7日ごとに更新）。

## Android 版でできていること（1.0.24 時点）

- **再生**：libVLC で古い形式・AC3/DTS・ASS 字幕まで再生。画面を離れても字幕・音声トラックの選択などが残る。小窓（PiP）、バックグラウンド再生、電話中の一時停止。
- **字幕**：自動読み込み、文字コード変換（Shift_JIS など）、タイミング調整。
- **再生画面**：中央に大きな前へ・再生・次へのボタン、下に道具ボタン。ピンチで拡大、速度スライダー、A-Bリピート、チャプター、スクリーンショット、音量ブースト、時間を指定して移動。初期設定は自動回転。操作パネルの表示中はシステムバーも表示する。
- **メニュー**：︙・字幕・音声などのメニューは、アイコン付きで下から出るメニュー。
- **一覧**：動画・音楽・フォルダ・履歴・プレイリストのタブ。検索・並べ替え・グリッド表示。サムネイルはキャッシュ。
- **お気に入り**：フォルダはフォルダタブの一番上、動画・曲はプレイリストタブの「お気に入り」。
- **ファイル操作**：共有・詳細・名前の変更・削除。
- **ネットワーク**：NAS（SMB）・DLNA・URL・Chromecast へのキャスト。パスワードは暗号化して保存。
- **そのほか**：テーマ（暗い・明るい・端末に合わせる）、Android TV 対応、テスト（`android/app/src/test`）。

ユーザーの実機で 1.0.24 まで「いまのところ問題なし」と確認済み。

### 1.0.26〜1.0.28 で追加（2026-10-08）

- **自由な小窓**（`PopupPlayer.kt`・`PopupGeometry.kt`）：ほかのアプリの上に重ねて出す Orbit 自身の小窓。「他のアプリの上に重ねて表示」の許可が要る。ボタン（閉じる・全画面・戻る・前へ・再生・次へ・進む。幅に合わせて数が変わる）、ドラッグで移動・画面の端まで寄せられる、ピンチと右下のつまみで大きさ（長い辺 96dp まで小さくできる）。大きさと場所は次回も同じ。1.0.26 では許可をお願いする画面が出ずに OS の小窓になっていたので、1.0.28 で再生画面を開いたときに一度だけ許可をお願いするようにした。「画面を離れたとき」の初期設定をこれにした（許可が無いあいだは OS の小窓で代わりに再生）。
- OS の小窓（ピクチャーインピクチャー）：ボタンを 5 個まで出せる端末では前へ・次へも出す（多くのスマホは 3 個まで）。
- **長押しで 2 倍速**：押している間だけ。設定の「ジェスチャー」でオフにできる。
- **シーク中のプレビュー**（`SeekThumbnails.kt`）：シークバーのつまみの上に、その位置の画像と時間。端末内のファイルだけ。画像を作れない動画は今までどおり映像そのものが動く。

### 1.0.34 で追加（2026-10-10）

ユーザーの実機で 1.0.34 を試してもらい「とりあえず問題なし」。

コード全体を見直して見つけた問題を、まとめて直した。
- **一時停止のあと**：すぐ常駐をやめずに 30 分待つ（画面で見ている間・電話中は待ち続ける）。止められても押せない通知を残さない。再生キューを `last_session.json` に覚えておき、通知・イヤホン/Bluetooth の再生ボタン（`MediaButtonReceiver`）・再生画面に戻ったときに前回の続きを戻す。終了ボタンや最後まで再生して終わったものは、画面に戻っても戻さない（ボタンで頼まれたときは戻す）。
- 「動画」タブの「すべて」から見た動画は、終わったら止まる（設定「「動画」タブ：終わったら次の動画を再生」、初期はオフ）。フォルダ・プレイリストからは次へ進む。
- NAS の動画でも隣の字幕を読む。ネットワークのフォルダの中身を覚えておく（フォルダ名タップで読み直し）。キャスト中に戻るで閉じても止めない。履歴は動画だけ。名前の変更・削除をプレイリスト・お気に入り・履歴にも反映。設定の変更を再生画面に戻ったときに反映。音楽画面の復元。シャッフル＋全曲リピートの重複。字幕の文字コードを手で選べる。向きに「回転ロックに従う」。スクショは「ピクチャ/Orbit」。
- 軽くする改善（一覧の差分更新、通知の作り直しを減らす、フォルダ情報・パスワード復号・サムネイル失敗のキャッシュ）。署名鍵が無いときにビルドで警告。
- 再生キューの編集（長押しで今すぐ再生・次に再生・上へ・下へ・外す）。一覧の長押しに「次に再生」「再生キューに追加」。音楽タブのアルバム・アーティストにジャケット画像。
- 見送り：**字幕のダウンロード**（OpenSubtitles などは API キーとアカウント登録が必要なので、ユーザーに相談してから）。Android 13 以前では、一時停止中の通知を 30 分間スワイプで消せない（常駐を続けるため。終了ボタンで消せる）。

## iPhone 版でできていること（段階1・iOS 1.0.2 時点）

## 見送ったこと（理由つき）

- **Android の APK の縮小（R8）**：実機で確かめないと動かなくなる危険があるため。
- **大きなファイルの分割、Media3 への移行**：作り直しに近い規模で、見た目の改善がないため。
- **多言語対応**：日本語だけで使うため。
